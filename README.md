## 📖 О проекте

**СОВА** — это современная веб-платформа, созданная для того, чтобы помочь абитуриентам сделать осознанный и уверенный выбор будущего направления обучения и университета.

В отличие от стандартных агрегаторов, предлагающих лишь рекламные слоганы и устаревшие средние проходные баллы прошлых лет, **СОВА** позволяет заглянуть «под капот» каждой специальности:
- Сравнить реальное соотношение дисциплин (программирование, высшая математика, AI/ML, системная инженерия) по **официальным учебным планам** вузов;
- Разобраться в механике приёмной кампании без бюрократического канцелярита и стресса;
- Пройти весь путь от выбора предметов ЕГЭ до публикации приказов о зачислении в сопровождении дружелюбного маскота.

## 🦉 Маскот СОВА

Официальный маскот проекта — **СОВА**, мудрый и дружелюбный эксперт-наставник в академической конфедератке с золотой кисточкой:

- **Hero-экран:** встречает абитуриента приветственным взмахом крыла (`variant="waving"`), создавая тёплую и открытую атмосферу.
- **Интерактивный аватар в шапке (`InteractiveOwlAvatar`):** в режиме реального времени реагирует на прокрутку страницы:
  - При скролле **вниз** опускает взгляд и чуть наклоняет голову, внимательно изучая карточки программ вместе с пользователем;
  - При скролле **вверх** переводит взгляд к верхней панели фильтров;
  - При остановке скролла плавно возвращает взгляд в нейтральное положение.
- **Экспертные подсказки и глоссарий:** комментирует каждый шаг поступления, предостерегает от роковых ошибок и подробно объясняет сложные термины простыми словами в модальных окнах.

## 🚀 Ключевые возможности

### 1. 🌟 Главный экран (Hero Landing)
- Разработан по мотивам авторского дизайн-скетча «Вся логика вместе».
- Маскот СОВА и слоган: *«Привет! Я СОВА, давай я помогу тебе с поступлением!»*.
- Информационная дорожка: **Понять** (знания о приёме) → **Сравнить** (учебные планы) → **Выбрать** (осознанное решение).
- Крупная тактильная Duolingo-кнопка **«Давай приступим»** для мгновенного перехода к подбору программ.

### 2. 📋 Интерактивный онбординг (7 шагов в стиле Duolingo)
1. **Знакомство:** ввод имени абитуриента для персонального диалога.
2. **Город:** выбор приоритетного региона обучения (Москва, Санкт-Петербург, Нижний Новгород, Казань, Екатеринбург и др.).
3. **Статус ЕГЭ:** знаю точные баллы / ещё не сдавал / ориентировочные результаты.
4. **Предметы ЕГЭ:** выбор сдаваемых дисциплин (русский язык, профильная математика, информатика, физика, обществознание и др.).
5. **Баллы:** ввод баллов по каждому предмету с валидацией (0–100).
6. **Индивидуальные достижения (ИД):** учёт золотой/серебряной медали, знака ГТО, волонтёрства и олимпиад (до +10 дополнительных баллов).
7. **Каталог результатов:** мгновенный расчёт шансов на бюджет и платное обучение.

### 3. 🎓 Каталог и умный подбор программ (`ProgramsResults`)
- **Алгоритм матчинга:** расчёт суммы баллов абитуриента, сопоставление с минимальными порогами каждого вуза и проходными баллами прошлых лет.
- **Фильтры и поиск:**
  - Быстрые вкладки: *Все программы*, *Только бюджет*, *Платное*, *ИТ-направления*.
  - Фильтры по городам и конкретным университетам.
  - Полнотекстовый живой поиск по названию программы, вузу, факультету или тегам.
- **Карточка программы:** статус прохождения (бюджет/платно), стоимость обучения за год, количество бюджетных мест, наличие общежития, военного учебного центра и государственной аккредитации.
- **Режим сравнения:** кнопка «Сравнить» с сохранением выбранных программ (от 2 до 4) в `localStorage`.

### 4. ⚖️ Глубокое сопоставление учебных планов (`ProgramComparisonPage`)
Позволяет наглядно увидеть, чему реально учат на схожих специальностях в разных университетах:
- **14 сквозных категорий дисциплин:** Программирование, Высшая математика, Алгоритмы и структуры данных, Инженерные системы, Машинное обучение / AI, Базы данных, Анализ данных, Программная инженерия, Физика, Иностранный язык, Практика и проекты и др.
- **Два режима отображения:**
  - **«Обзор» (по категориям):** наглядные капсульные шкалы-индикаторы с долями дисциплин в общем объёме программы + переключатель *«Только различия»* ($\ge 3\%$).
  - **«Учебный план»:** покурсовая разбивка дисциплин (1–4 курс) с указанием академических часов и зачётных единиц (З.Е.).
- **Аналитика различий:** автоматический беспристрастный вывод фактов о смещении фокуса (например, фундаментальная математика vs прикладная разработка и MLOps).
- **Реальные данные:** официальные учебные планы бакалавриата (на примере 01.03.02 ПМИ НИУ ВШЭ НН vs ПМИ ННГУ им. Лобачевского).

### 5. 🧭 Гид по приёмной кампании («Этапы поступления 2026»)
Три специализированных формата подачи информации:

1. **«По шагам»:**
   - 6 интерактивных этапов (от выбора программ до издания приказов) с прогресс-баром и фиксацией выполненных шагов.
   - Реплики эксперта СОВЫ, разбор ситуаций «На твоём примере», выдержки из приказов Минобрнауки и практические чек-листы.
2. **«Простым текстом»:**
   - Полный связный пошаговый рассказ о поступлении от начала до конца (Шаги 1–7 + Золотые правила).
   - **Главный нюанс направлений и программ:**
     - Лимит подачи: до 5 вузов, до 5 направлений/специальностей в каждом.
     - Разбор скрытой возможности: внутри одного направления может быть несколько образовательных программ (на примере 5 направлений и 9 программ).
     - Ответ на вопрос: *почему в конкурсных списках бывает 10, 15 и более приоритетов?*
     - Формула запоминания: **Вуз → Направление → Образовательная программа**.
   - Подача через Суперсервис Госуслуг и обезличенные списки по **индивидуальному коду**.
   - Логика работы приёмного робота: автоматическая проверка приоритетов сверху вниз и аннулирование низших приоритетов.
   - Приоритетный этап: льготные квоты (целевая, особая, отдельная) и право БВИ для олимпиадников.
   - Высший проходной приоритет (**ВПП**) и Очередной высший приоритет (**ОВП**).
   - Решающий дедлайн подачи оригинала документа об образовании (строго до 12:00 мск).
   - Дозачисление и образовательный кредит с господдержкой (3%).
3. **«Официально»:**
   - Нормативная база: ФЗ-273 «Об образовании в РФ», приказ Минобрнауки № 1076.
   - Официальный календарь с точными юридическими датами кампании 2026 года.
   - Прямые ссылки на государственные платформы (Госуслуги, «Работа в России», ФИПИ).
4. **Интерактивный глоссарий терминов:**
   - Все ключевые термины (ВПП, ОВП, БВИ, ИД, квоты, минимальный балл и др.) кликабельны и снабжены иллюстрированными модальными окнами с понятными объяснениями от Совы.

### 6. 🍔 Боковое меню профиля (Side Menu Drawer)
- Вызывается по клику на бургер-кнопку в верхнем правом углу шапки.
- Шапка профиля со статичным аватаром СОВЫ в конфедератке и текущим городом.
- Разделы: *Личный кабинет* (редактирование имени и города), *Этапы поступления от Совы*, *Сравнить программы*, *Изменить баллы ЕГЭ*, *Полезные ссылки*, *Начать сначала*.
- Блок обратной связи для предложений и идей внизу панели.

## 💻 Установка и запуск

### Предварительные требования
- Установленный **Node.js** версии 18+ (рекомендуется 20+)
- Менеджер пакетов **npm**

### Быстрый старт

1. **Клонируйте репозиторий или перейдите в папку проекта:**
   ```bash
   cd sova
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите локальный сервер разработки:**
   ```bash
   npm run dev
   ```
   После запуска приложение будет доступно по адресу `http://localhost:5173`.

4. **Сборка для продакшена:**
   ```bash
   npm run build
   ```

5. **Проверка качества кода линтером:**
   ```bash
   npm run lint
   ```

6. **Локальный предпросмотр продакшен-сборки:**
   ```bash
   npm run preview
   ```

## 🎨 Дизайн-система и принципы

- **Тактильный стиль Duolingo:** дружелюбная цветовая палитра, крупные скругления (`rounded-2xl`, `rounded-3xl`), объёмные нижние грани кнопок (`border-b-[3px]`, `border-b-[4px]`) с физическим откликом при нажатии (`active:translate-y-[2px]`).
- **Строгая доступность и приватность:** во всех текстах и интерфейсах соблюдается конфиденциальность — используется термин **«индивидуальный код»** в соответствии с правилами ранжированных списков приёма в РФ.
- **Интерактивность:** маскот не является статичной картинкой — он реагирует на действия пользователя и помогает ориентироваться в плотном потоке информации.
